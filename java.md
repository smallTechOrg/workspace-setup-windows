# java Setup — Windows

## Purpose
Set up your Java development environment on a new Windows machine using the latest LTS version of the JDK.

## 1. Download java
Download the JDK (Java SE development kit) 25.0.1 version for the LTS version.

Oracle website:

https://download.oracle.com/java/25/latest/jdk-25_windows-x64_bin.exe

Run the installer

## 3. Restart the terminal

After installation, close current PowerShell and open a new PowerShell window.

## 4. Verify java

Restart git bash and verify the installation
```bash
java --version
```
